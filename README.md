# Mi Espacio — Personal Hub PWA

App personal con 5 secciones: Documentos, Webs favoritas, Listas, Screenshots y Aprendizaje.

## 🚀 Deploy en Vercel (3 pasos)

### Opción A — GitHub + Vercel (recomendado)
1. Sube esta carpeta a un repo de GitHub
2. Ve a [vercel.com](https://vercel.com) → New Project → importa el repo
3. Vercel detecta Vite automáticamente → **Deploy** ✅

### Opción B — Vercel CLI
```bash
npm install -g vercel
cd mi-espacio
npm install
vercel
```

## 💻 Desarrollo local
```bash
npm install
npm run dev
```

## 📦 Build
```bash
npm run build
```

## 📱 Instalar como PWA
Una vez desplegada, abre la URL en móvil → menú del navegador → "Añadir a pantalla de inicio"
